# Задание: Pawdex

## Что строим

Pawdex — мобильное приложение-игра про уличных кошек и собак. Игрок фотографирует животное на улице, приложение определяет, кошка это или собака, и пытается узнать конкретное животное (не породу, а именно «это Толстый Мо, его видели 14 раз»). Каждое реальное животное — это живая карточка в коллекции: с редкостью, прозвищем, первооткрывателем и фотолетописью встреч. Всё это на карте района.

Стартовый регион — Вьетнам (Хошимин, Далат), дальше любые города. Приложение международное: Турция (Стамбул), Россия, Азия, Северная Америка и т.д. Интерфейс пока на английском, перевод на другие языки — позже.

## Стек

- Мобильное приложение: Flutter (iOS + Android из одного кода).
- Бэкенд: Python 3.12, FastAPI.
- База: PostgreSQL + PostGIS (гео-запросы «животные в радиусе N метров»), pgvector (поиск похожих эмбеддингов).
- Хранилище фото: локально на диске в dev, интерфейс сделать так, чтобы потом заменить на S3-совместимое.
- ML на сервере:
  - определение «кошка / собака / ни то ни другое» — готовая предобученная модель (например, YOLO или CLIP zero-shot, выбрать самое простое и надёжное);
  - эмбеддинг конкретного животного для узнавания — предобученная модель (например, DINOv2 или CLIP), без обучения своей модели на старте.
- Локальный запуск: docker compose (api + postgres). Одна команда — всё поднялось.

Если какой-то выбор выше кажется неудачным — предложить альтернативу и объяснить почему, прежде чем менять.

## Ключевые правила продукта

1. **Узнавание сравнивает только с соседями.** Новое фото сравнивается с животными того же вида в радиусе ~300 м, а не со всей базой.
2. **Когда не уверен — спроси игрока.** Три исхода: уверенное совпадение («Это Мо!»), неуверенное («Это Мо или новый?» — игрок выбирает), новое животное. Пороги похожести — в конфиге.
3. **Безопасность животных.** Во Вьетнаме домашних животных воруют. Точные координаты хранятся только на сервере. Наружу (в API для карты) отдаётся только округлённая зона (ячейка ~250–500 м, например через geohash). Жёсткое требование, покрыть тестом.
4. **Первооткрыватель.** Кто первым сфотографировал новое животное, тот даёт ему имя. Имя остаётся навсегда.

## Фазы

Работать строго по фазам. После каждой фазы остановиться, показать, что сделано, как запустить и проверить, и ждать «ок» перед следующей.

### Фаза 0 — скелет
- Структура репозитория: `/app` (Flutter), `/api` (FastAPI), `docker-compose.yml`, `README.md`.
- FastAPI с эндпоинтом `/health`, подключение к Postgres, миграции (Alembic), PostGIS и pgvector включены.
- Flutter-приложение с одним экраном «Hello Pawdex», которое дёргает `/health` и показывает ответ.
- README: как всё запустить с нуля, по шагам.

### Фаза 1 — сфоткал и определил
- Экран камеры / выбора фото, отправка фото + координат на сервер.
- `POST /sightings`: принимает фото и координаты, определяет вид (кошка/собака/нет животного), сохраняет встречу.
- Если животного на фото нет — понятный ответ, фото не сохраняется.
- Экран «Мои встречи» — список моих фото с видом.
- Простая авторизация: анонимный пользователь с id на устройстве.
- Тесты на эндпоинт и на классификацию (на нескольких тестовых картинках).

### Фаза 2 — узнавание конкретного животного
- Эмбеддинг для каждого фото, хранится в pgvector.
- При новой встрече — поиск похожих того же вида в радиусе, три исхода из правила 2.
- Сущности `Animal` и `Sighting`, встреча привязывается к животному.
- Экран «Это он или новый?» и экран «Дай имя» для первооткрывателя.

### Фаза 3 — карта
- Карта с животными вокруг, только по округлённым зонам (правило 3).
- Тап по зоне — какие животные там живут.

### Фаза 4 — карточки и редкость
- Карточка животного: имя, первооткрыватель, число встреч, фотолетопись.
- Редкость (обычная / редкая / легендарная) — простые правила в конфиге.
- «Поделиться» — картинка-карточка для соцсетей.
- Справка по окрасу: настоящие факты про окрас (трёхцветные — почти всегда самки, рыжие — чаще самцы, «тигровый» рисунок — древнейший).
- Порода — только когда модель уверена (иначе «беспородная», и показываем окрас). Список пород международный (~70: Турция, Россия, Азия, Америка, популярные мировые), у каждой — происхождение и краткая история, только проверенные факты.
  - Порода НЕ влияет на редкость (редкость — по окрасу), чтобы не поощрять охоту за чужими породистыми питомцами.
  - Порода видна только в карточке животного, не на карте и не в списках зоны: породистых животных воруют чаще всего.
